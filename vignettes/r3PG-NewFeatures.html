Introduction

r3PG provides an R interface to the 3-PG forest growth model (Landsberg & Waring, 1997). Version 0.2.0 adds several major capabilities:

  • New mortality models (mort_model = 2 and mort_model = 3) that allow the self-thinning line to shift with long-term site conditions.
  • Biomass-based thinning as an alternative to specifying the number of retained stems.
  • Defoliation events to simulate pruning, coppicing, epicormic resprouting, and stand-replacing disturbances.
  • Multi-cohort regeneration for simulating uneven-aged or mixed-age stands with sequential planting and thinning to zero stems.

This vignette walks through each feature with fully reproducible examples using the built-in datasets d_mixture, d_regeneration, and d_defoliation. For a general introduction to r3PG, see vignette("r3PG").

library(dplyr)

Quick review: running a basic simulation

The central function is run_3PG(). It expects tables for site conditions, species initial states, climate forcing, and (optionally) thinning, defoliation, parameters, size distributions, and model settings. All built-in datasets bundle these tables into a single list; for example, d_mixture contains a two-species mixed stand of Fagus sylvatica and Pinus sylvestris.

out_mix <- run_3PG(
  site       = d_mixture$site,
  species    = d_mixture$species,
  climate    = d_mixture$climate,
  thinning   = d_mixture$thinning,
  parameters = d_mixture$parameters,
  size_dist  = d_mixture$sizeDist,
  settings   = list(light_model = 2, transp_model = 2, phys_model = 2,
                    height_model = 1, crown_width_model = 1,
                    calculate_d13c = 0, mort_model = 3),
  check_input = TRUE, df_out = TRUE)

Mortality models

3-PG v0.2.0 offers three mortality approaches. All include the same density-independent background mortality (declining with age), but they differ in how they calculate density-dependent (self-thinning) mortality.

Setting Description
mort_model = 1 Original 3-PGpjs method. Maximum individual-tree stem mass (wSx1000) determines when self-thinning begins.
mort_model = 2 Self-thinning line intercept can shift with long-term nutrition, temperature, and physiological modifiers (st_Power, st_Intercept, st_fN, st_fT, st_fPhys).
mort_model = 3 Growth-based mortality where the change in tree density is a function of the change in stem diameter, modified by long-term site conditions (beta0 through betafPhys).

For mort_model = 2 and 3, the self-thinning parameters are site-level (not species-level) inputs, because all cohorts within a stand share the same self-thinning boundary. These are supplied through the site table in columns such as st_Power, beta0, etc.

Long-term modifiers

Both mort_model = 2 and 3 optionally use rolling averages of three growth modifiers (nutrition, temperature, physiological) to shift the self-thinning line. The averaging window is set by the lt_mod_mths column in the site table (in months). For example, lt_mod_mths = 120 uses a 10-year rolling average.

Comparing mortality models

We can compare mort_model = 1 and mort_model = 3 side-by-side using d_mixture:

run_with_mort <- function(mort) {
  run_3PG(
    site       = d_mixture$site,
    species    = d_mixture$species,
    climate    = d_mixture$climate,
    thinning   = d_mixture$thinning,
    parameters = d_mixture$parameters,
    size_dist  = d_mixture$sizeDist,
    settings   = list(light_model = 2, transp_model = 2, phys_model = 2,
                      height_model = 1, crown_width_model = 1,
                      calculate_d13c = 0, mort_model = mort),
    check_input = TRUE, df_out = TRUE) |>
    mutate(mort_model = paste0("mort_model = ", mort))
}

out_mort <- bind_rows(run_with_mort(1), run_with_mort(3))

i_var <- c("stems_n", "dbh", "biom_stem", "basal_area")
i_lab <- c("Stem density (trees/ha)", "DBH (cm)",

out_mort |>

  ggplot(aes(date, value, color = species, linetype = mort_model)) +

The newer mortality models (mort_model = 2 and 3) allow the self-thinning boundary to respond to site productivity, producing more realistic density trajectories for stands under varying growing conditions.

Thinning

Standard thinning (retained stems)

Thinning events are specified through a data frame with columns species, age, stems_n, stem, root, and foliage. The stems_n column gives the retained stem count after thinning. The stem, root, and foliage columns describe the relative size of removed trees compared to the mean tree (values < 1 = thinning from below; > 1 = thinning from above; 1 = uniform).

Biomass-based thinning (retained proportion)

New in v0.2.0, thinning intensity can alternatively be specified as the proportion of aboveground biomass retained, using the optional column biom_prop_retained (a value between 0 and 1). When this column is provided and is not NA, it overrides stems_n. This is useful when the management prescription is defined in terms of retained basal area or biomass rather than stem count.

# Create a biomass-based thinning event: retain 50% of aboveground biomass
thinning_biom <- data.frame(
  species            = "Fagus sylvatica",
  age                = 48,
  stems_n            = NA,
  stem               = 1,
  root               = 1,
  foliage            = 1,
  biom_prop_retained = 0.5
)

out_biom_thin <- run_3PG(
  site       = d_mixture$site,
  species    = d_mixture$species,
  climate    = d_mixture$climate,
  thinning   = thinning_biom,
  parameters = d_mixture$parameters,
  size_dist  = d_mixture$sizeDist,
  settings   = list(light_model = 2, transp_model = 2, phys_model = 2,
                    height_model = 1, crown_width_model = 1,
                    calculate_d13c = 0, mort_model = 3),
  check_input = TRUE, df_out = TRUE)

Each cohort grows, self-thins, and is eventually removed at age 90. New cohorts are planted every 20 years, creating a continuous uneven-aged canopy. It is recommended to use the lowest number of cohorts that captures the size structure of interest, because prediction biases in one cohort propagate to others through competition for light and water.

Defoliation events

Defoliation is a new input category in v0.2.0. It simulates the removal of foliage (and optionally stem and root biomass) to represent events such as pruning, fire, pest damage, coppicing, or epicormic resprouting. The built-in dataset d_defoliation provides an example for a single-species stand.

Defoliation input structure

The defoliation table requires the following columns:

Column Description
species Species name matching the species table
age Stand age (years) at which the event occurs
def_type Type of defoliation event: 1 = pruning, 2 = coppice, 3 = epicormic, 4 = stand-replacing
stem_retained Proportion of stem biomass retained (per stand)
foliage_retained Proportion of foliage biomass retained (per tree)
root_retained Proportion of root biomass retained (per stand)
stem Currently reserved (set to 1)
def_recover_t Maximum recovery time in months (must be ≥ 2)
prop_carbs Proportion of 1st-year NPP from stored non-structural carbohydrates
prop_npp Proportion of new NPP partitioned to foliage (pruning/epicormic) or foliage+stem (coppice)

The four defoliation types have distinct constraints on the retained proportions:

Type Foliage retained Stem retained Root retained
Pruning (1) < 1 1 1
Coppice (2) 0 0 > 0
Epicormic (3) < 1 > 0 (= root) > 0 (= stem)
Stand-replacing (4) 0 0 0

Key processes after defoliation

Following a defoliation event, 3-PG modifies growth in two ways:

  1. Stored carbohydrate use (prop_carbs): A fraction of NPP is assumed to come from non-structural carbohydrate reserves, temporarily boosting foliage (and stem, for coppice) regrowth. This is particularly important for coppice events where all foliage is removed and photosynthetic NPP is initially zero.

  2. Modified partitioning (prop_npp): The fraction of NPP partitioned to foliage is temporarily increased at the expense of stem or root partitioning, reflecting the observed prioritisation of crown rebuilding after defoliation. This shift persists until the pre-defoliation foliage mass is restored or the maximum recovery time (def_recover_t) is reached.

At the defoliation age, stem density drops from its pre-event value to 50% (reflecting tree mortality from the event), while foliage mass declines to 60% of the pre-event per-tree value (times the surviving trees). The modified partitioning and carbohydrate use then accelerate foliage recovery.

Simulating different defoliation types

You can modify d_defoliation$defoliation to simulate other event types. Below we show how to set up each type.

Pruning

Pruning removes some foliage but keeps all stem and root biomass. Only the surviving trees’ crowns are trimmed.

defol_pruning <- data.frame(
  species          = "Pinus sylvestris_1",
  age              = 30,
  def_type         = 1,
  stem_retained    = 1,
  foliage_retained = 0.5,
  root_retained    = 1,
  stem             = 1,
  def_recover_t    = 36,
  prop_carbs       = 0.2,
  prop_npp         = 0.6
)

Coppice

Coppice removes all foliage and stem biomass but retains the root system. The cohort age is reset to zero after a coppice event, allowing the stand to regrow from the existing root stock.

defol_coppice <- data.frame(
  species          = "Pinus sylvestris_1",
  age              = 20,
  def_type         = 2,
  stem_retained    = 0,
  foliage_retained = 0,
  root_retained    = 1,
  stem             = 1,
  def_recover_t    = 12,
  prop_carbs       = 0.3,
  prop_npp         = 0.6
)

Epicormic

Epicormic events kill some trees (reducing stem and root proportionally) and remove some foliage from survivors. The retained stem proportion must equal the retained root proportion.

defol_epicormic <- data.frame(
  species          = "Pinus sylvestris_1",
  age              = 70,
  def_type         = 3,
  stem_retained    = 0.5,
  foliage_retained = 0.6,
  root_retained    = 0.5,
  stem             = 1,
  def_recover_t    = 60,
  prop_carbs       = 0.4,
  prop_npp         = 0.8
)

Stand-replacing disturbance

A stand-replacing event (e.g. severe fire) removes all biomass. This is equivalent to clearing the cohort entirely.

defol_standrep <- data.frame(
  species          = "Pinus sylvestris_1",
  age              = 50,
  def_type         = 4,
  stem_retained    = 0,
  foliage_retained = 0,
  root_retained    = 0,
  stem             = 1,
  def_recover_t    = 2,
  prop_carbs       = 0,
  prop_npp         = 0
)

Comparing a defoliated vs. undisturbed stand

A useful analysis is to compare the same stand with and without a defoliation event:

run_defol <- function(defoliation_df = NULL, label = "none") {
  run_3PG(
    site        = d_defoliation$site,
    species     = d_defoliation$species,
    climate     = d_defoliation$climate,
    thinning    = d_defoliation$thinning,
    defoliation = defoliation_df,
    parameters  = d_defoliation$parameters,
    size_dist   = d_defoliation$sizeDist,

                       height_model = 1, crown_width_model = 1,
                       calculate_d13c = 0, mort_model = 3),

Model settings reference

The settings argument to run_3PG() controls which sub-models are active. The table below summarises all available settings:

Setting Values Description
light_model 1 (default), 2 1 = 3-PGpjs Beer–Lambert with typical k; 2 = 3-PGmix light model with homogeneous-canopy kH
transp_model 1 (default), 2 1 = 3-PGpjs; 2 = 3-PGmix (within-canopy VPD, aerodynamic resistance, soil evaporation)
phys_model 1 (default), 2 1 = min(f_vpd, f_sw); 2 = f_vpd × f_sw
height_model 1 (default), 2, 3 Height allometry form: 1 = exponential; 2 = Michajlow; 3 = Näslund
crown_width_model 1 (default), 2, 3 Crown width allometry form: 1 = exponential; 2 = Michajlow; 3 = Näslund
calculate_d13c 0 (default), 1 Whether to calculate δ¹³C of wood
mort_model 1 (default), 2, 3 Mortality approach (see section above)

For 3-PGpjs (monospecific, even-aged, evergreen), use all defaults (1). For 3-PGmix (mixed, uneven-aged, or deciduous), set light_model = 2, transp_model = 2, phys_model = 2.

Summary

r3PG v0.2.0 significantly extends the modelling capabilities of the package:

  • Three mortality models give users flexibility from the simple wSx1000-based approach to modifier-adjusted self-thinning lines.
  • Biomass-based thinning supplements the traditional stem-count approach.
  • Four defoliation types cover common disturbance and management scenarios (pruning, coppice, epicormic, stand-replacing), each with configurable recovery dynamics.
  • Multi-cohort stands with sequential planting and removal enable realistic uneven-aged forest simulations.

For the mathematical details behind these features, see Forrester (2026) 3-PG: Equations, data requirements and calculation of parameters.
